# create-alambic

Scaffold a new Alambic Shopify theme project.

## Usage

```bash
pnpm create alambic my-theme
cd my-theme
pnpm install   # if you passed --no-install
pnpm dev
```

## Options

- `--template <name>` — Starter template (default: `tailwind-alpine`).
- `--no-install` — Skip package install after scaffold.
- `--no-git` — Skip `git init`.
